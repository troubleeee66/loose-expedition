# 다시 숟가락 얹기

공익활동을 떠났거나 간헐적으로 참여하는 사람들의 이탈 경험을 기록하고, 의무 없이 거리를 스스로 정하며 다시 이어질 수 있는 방식을 만드는 프로젝트입니다.
느슨한 원정대가 2026 숲과나눔 풀씨 13기 활동으로 진행했습니다.

## 프로젝트 소개

- 공익활동 현장의 이탈은 개인의 열정 문제가 아니라 "전부 아니면 전무"를 요구하는 참여 구조에서 반복된다는 문제의식에서 출발했습니다.
- 공익활동 이탈·간헐 참여 경험자 34명의 설문과 9명의 대면 인터뷰로 이탈의 구조적 원인과 재참여 조건을 분석했습니다.
- 분석 결과를 공개 아카이브, 조직 자가점검 체크리스트, 유형 검사, 후속 활동(글벗·마실·사이)으로 옮겼습니다.

## 페이지 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 입구 페이지. 후속 활동과 유형 검사로 이어지는 시작점 |
| `archive.html` | 느슨한 아카이브. 인터뷰이 9명을 익명화해 정리한 공개 아카이브 (기본 버전) |
| `archive-mint.html` | 같은 아카이브의 민트 테마 버전 |
| `type.html` | 숟가락 유형 검사. 참여 방식을 알아보는 12유형 검사 (응답 데이터는 저장하지 않음) |
| `letter.html` | 글벗. 손편지를 주고받는 활동 안내 |
| `together.html` | 마실. 영화, 축제, 북클럽처럼 함께 행사에 가는 활동 안내 |
| `yard.html` | 사이. 가끔 만나는 오프라인 모임 안내 |
| `survey.html` | 사전 설문 양식 |
| `robots.txt` | 검색엔진 수집 설정 |

## 후속 활동

후속 활동의 목적은 느슨한 재참여 연대입니다. 하나만 또는 여러 개를 고를 수 있고 나중에 추가해도 됩니다.

- **글벗**: 손편지를 주고받습니다. 닉네임과 짧은 소개 카드만 공개하고, 받는 사람이 수락하면 주소가 전달됩니다. 정해진 주기가 없고, 카드 한 장은 최대 3번 연결됩니다.
- **마실**: 영화, 축제, 북클럽처럼 함께 행사에 갑니다. 인원 제한이 없습니다.
- **사이**: 가끔 만나는 오프라인 모임입니다. 주기와 인원 제한이 없습니다.

호스트는 돌아가며 맡고, 호스트 비용은 재원이 확보될 때 보전을 검토하며 활동 인증서를 제공합니다. 신청 창구는 아직 열지 않았습니다.

## 아카이브 이용 시 유의사항

- 아카이브의 인터뷰이는 모두 익명이며, 알파벳 표기는 활동 정보를 구분하기 위한 임의 표기입니다.
- 인용은 인터뷰이가 직접 한 말과 요약된 표현을 구분해 표시했습니다. 요약은 ‘ ’로 표시합니다.
- 표본은 참여 신청자 중 인터뷰가 성사된 사람이어서 대표성을 갖지 않습니다. 조직 경험자 중심이고, 조직 밖에서 혼자 실천하던 사람과 완전히 떠난 사람의 이야기는 상대적으로 적을 수 있습니다.
- 아카이브의 내용을 인용하거나 공유할 때는 출처를 밝혀 주세요. 인터뷰이를 특정하려는 시도는 하지 말아 주세요.
